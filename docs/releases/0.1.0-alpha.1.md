# OpenClaw OS 0.1.0-alpha.1

This is the first installable OpenClaw OS technical alpha. It is intended for
disposable amd64 virtual machines and controlled lab systems. It is not a
production appliance.

## What is included

- Debian 13 `trixie` hybrid installer media
- pinned Node.js 24 LTS and OpenClaw extended-stable runtime
- hardened unprivileged Gateway and read-only local control plane
- rootless Podman-backed tool sandboxes and default-deny inbound firewall
- local maintenance console, verified backups, audits, and policy profiles
- staged OpenClaw application updates with code rollback and failed-candidate quarantine
- UEFI live-boot plus automated UEFI and BIOS blank-disk installation tests
- installed-system OpenClaw stage, apply, rollback, and reapply verification
- SHA-256 checksums, SPDX 2.3 SBOM, build manifest, and release-evidence record

## Known limitations

- amd64 only
- QEMU is the only tested hardware for this release
- no supported upgrade path from an earlier OpenClaw OS release
- no transactional Debian base-OS rollback
- no Secure Boot signing, measured boot, or automated full-disk encryption
- no production OpenClaw OS update-signing trust root or first-party OS update feed
- OpenClaw code rollback does not automatically restore migrated application state
- compatibility and broad update-channel support remain development claims, not stable support guarantees

## Tested hardware

- QEMU `q35` with OVMF UEFI
- QEMU `pc` with legacy BIOS

No physical-hardware support claim is made by this alpha.

## Supported upgrade paths

Fresh installation is the only supported OpenClaw OS path. The installed-system
test does exercise the OpenClaw application transaction from the previous
tested application release to the pinned candidate, rollback to the previous
release, and reapplication of the candidate.

## Checksums and SBOM

Verify the attached ISO with its `.iso.sha256` asset. Verify the SPDX 2.3 SBOM
with its `.sbom.spdx.json.sha256` asset. The SBOM inventories Debian packages,
Node.js, the control plane, OpenClaw, and installed production npm dependencies.

## Signing identities

This lab alpha is unsigned. It is published by the repository's GitHub Actions
workflow only after binding the exact successful `main` artifact, source commit,
checks, installed-system evidence, issue snapshot, and 24-hour soak period.
Use the attached checksums and release-evidence record to verify identity.

## Rollback and recovery

OpenClaw application rollback is documented in `docs/UPDATES.md`. Code rollback
and application-state restoration are deliberately separate. For Debian base-OS
failure in this alpha, preserve verified backups and reinstall the appliance.
